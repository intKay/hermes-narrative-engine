# genre-chinese-myth

## 核心机制

### 阴气值（0-100）

玩家初始阴气值 = 0。

阴气累积场景：
- 进入凶宅/墓地：+5 到 +20
- 接触鬼物/阴物：+10 到 +30
- 破坏禁忌：+10 到 +25
- 子时（23:00-1:00）在外逗留：每 15 分钟 +2

阳气/护身手段：
- 朱砂 / 符咒：临时 -10 到 -20
- 桃木剑 / 黑狗血：强制退鬼判定
- 公鸡啼鸣：环境阳气回复
- 日出后：阴气自然缓慢下降（每小时 -3）

### 禁忌系统

违反禁忌会累积阴气并触发事件。规则怪谈式生存原则：

| 禁忌 | 违反后果 |
|------|---------|
| 午夜不照镜子 | 镜中影像可能不同步 |
| 纸人点睛会活 | 纸人有了「自己的方向」 |
| 走夜路不回头 | 肩上的灯会被吹灭 |
| 雨夜不收门口伞 | 会有「人」撑走它 |
| 捡到的钱立刻花掉 | 不花会有「人」来要 |

叙事中的原则：违反前必有预兆。先三次暗示，第四次触发。

### 叙述原则

1. **不直接描写鬼怪外形**——通过「不对劲」的细节暗示：
   - 纸人的位置变了
   - 桌上多了一副没人用过的碗筷
   - 脚步声在你停下之后继续响了两步
   - 窗玻璃上有一个手印——从里面按的

2. **重视规矩和禁忌的仪式感**——违反前的三次预兆要清晰可辨

3. **融合民俗知识**——黄历、风水、节气、时辰，增强文化真实感

4. **恐怖源于「违反日常秩序」**——不是血腥暴力，是熟悉的东西变得不对劲

### 口吻调节

- 正常状态：平实叙述，像老人在讲过去的事
- 阴气 > 40：语气渐冷，出现「你不记得……」开头的句子
- 阴气 > 70：出现自称紊乱（「我们」代替「我」），章节中出现不属于剧情的文字

### 三拍法则（每轮叙事输出格式）

每轮叙事严格按照以下结构生成：

```
第一拍（感官）—— 1-2 句环境描述
  功能：建立氛围。必选。

第二拍（推进）—— 0-1 句对上一轮选择的结果反馈
  功能：确认行动有效。必选。

第三拍（预兆）—— 0-1 句模糊的异常暗示
  功能：暗示禁忌即将被触发。可选，长度不超过 1 句。
```

整段叙事控制在 5 句以内。

### Fail Forward 示例（本类型）

中式怪谈的失败代价以**阴气上升**和**关系/禁忌破裂**为主：

```
侦察检定失败 → 你没找到你想找的东西。但你注意到——
                  你放在桌上的那盏油灯，火焰没有影子。
                  （阴气 +3，获得线索「这里有东西改变了光的性质」）

说服检定失败 → 老陈没有回答你。他只是盯着你身后的某处。
                  你看过去——什么也没有。但他看到的东西，
                  你看不到。（阴气 +5，陈默信任度 -10）
```

每个场景的 `on_fail` 必须同时包含"一个信息"和"一个代价"（阴气上升、禁忌触发、信任下降）。绝不返回「你什么也没发现」。

## 序幕场景模板

**场景：搬迁到老屋**

你因为工作调动，搬到了一座南方小城。单位给你安排的住处是一栋老式的三层自建房——外墙贴着白色瓷砖，但已经泛黄了，墙角长着青苔。你到的时候是下午四点多，阳光还很好，所以你第一眼并没有觉得这栋房子有什么问题。

房东把钥匙交给你的时候多说了一句：「三楼那间储物室别打开，里面堆的是以前住户的东西，跟别人签过保密协议的。」

你接过钥匙，点了点头。房东走后，你站在一楼的客厅里环顾四周。家具是旧的，但干净。桌上的杯子倒扣着，整齐地排成一排。窗户都关着，纱窗也没有破洞。一切看起来都很正常。

除了客厅正对门的墙上——挂着一面圆镜。镜面正对着大门。

你盯着那面镜子看了一会儿。你知道这种布局在风水上叫「镜煞」，但你可能只是多心了。

你接下来要怎么做？
A. 先把行李搬到二楼卧室
B. 去看看三楼那间储物室的门
C. 把那面镜子取下来换个位置
D. 检查一下房子里的所有门窗
