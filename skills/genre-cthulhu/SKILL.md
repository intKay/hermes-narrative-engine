# genre-cthulhu

## 核心机制

### SAN 值（0-100）

玩家初始 SAN = 85（非调查员，普通人上限）。

SAN 损失场景：
- 目睹超自然存在：-5 到 -30（视存在类型）
- 阅读禁书：-3 到 -15（视内容深度）
- 目睹同类尸体：-2 到 -5
- 遭受精神攻击：-5 到 -20

SAN 恢复场景：
- 安全休息：+1d3
- 与信任 NPC 交谈：+1d2
- 酒精/药物：+1d2（但可能影响判断力）

### 口吻调节

根据当前 SAN 值调整叙述风格：

| SAN 范围 | 叙述风格 |
|---------|---------|
| ≥ 80 | 冷静、法医式客观，细节丰富但克制 |
| 50–79 | 偶尔出现感官错位（"你闻到海腥味，虽然你在内陆"） |
| 20–49 | 时间线混乱，第二人称幻觉侵入（"你看见自己站在角落盯着你"） |
| < 20 | 现实崩解，时态混乱，直接对玩家的"认知"说话 |

### 三拍法则（每轮叙事输出格式）

每轮叙事严格按照以下结构生成：

```
第一拍（感官）—— 1-2 句环境描述（看见、听见、闻到）
  例：「门开了。一股潮湿、发霉的气味涌出来。里面很暗。」
  功能：建立氛围，不推进剧情。必选。

第二拍（推进）—— 0-1 句对上一轮选择的结果反馈
  例：「你走进去一步。脚下的地面不完全是实的——有一层积水。」
  功能：确认玩家的行动有效，推进位置或状态。必选。

第三拍（预兆）—— 0-1 句模糊的未来暗示
  例：「你没有注意到的是，你身后的门正在自行关闭。」
  功能：制造悬念，为下一轮的叙事蓄力。可选，长度不超过 1 句。
```

整段叙事控制在 5 句以内。不要在叙事中插入检定结果数字或任何元信息。

### 风格示范文本（嵌入此 Skill）
以下文本用于约束模型输出语气，高于任何风格描述：

```text
【氛围描写示范】
走廊尽头的灯在闪。不是电压不稳的那种闪——是有节奏的，
像某种信号。你数了一下：三短，三长，三短。然后停了。
你身后的墙壁里传来水管震动的声音，很低，像什么东西
在墙里呼吸。你确定在来的时候，这栋楼的水管没有经过这条走廊。

【NPC 对话示范】
「你听到了吗？」
陈默没有回头，他的声音很轻，像是怕惊动什么。
「我不确定那是什么。但我以前听到过——在缅甸的矿区，
地震之前，地底下的声音。跟这个一样。」
他终于转过头来。他的脸色在应急灯的冷光下发青。

【检定结果示范（成功）】
你找到一个被推到了书柜后面的铁皮箱。锁已经锈断了。
你不需要打开它——箱子侧面的缝隙里塞着一张泛黄的纸条，
露出一个角。你抽出来。纸上只有一句话，字迹很急：
「他们不在骨头里。在别的地方。」
外面忽然起风了。

【检定结果示范（失败=Fail Forward）】
你的手电筒扫过地下室的天花板。横梁上挂着蛛网，
厚得像一层布。你没有找到通风口的痕迹。
但你发现了一件事——你的呼吸，在空气里凝成了白雾。
现在是八月。这座地下室的温度，比上面低了至少十五度。
你没有发现你想找的东西。但你发现了这栋房子不该有的东西。
```

### 信息三层模型

| 层 | 获取方式 | 特征 |
|----|---------|------|
| 表层 | 直接观察 | 物理现实，可以用常识解释 |
| 调查层 | 搜集线索 + 技能检定 | 反常但尚未不可知 |
| 真相层 | 接触神话存在/禁书 | 认知污染，开始损失 SAN |

## 检定规则

D100 检定系统。标准难度梯度：

| 难度 | 目标值 | 适用场景 |
|------|--------|---------|
| 简单 | ≤ 75 | 常识范围内的行动 |
| 常规 | ≤ 55 | 需要一定技能的行动 |
| 困难 | ≤ 35 | 专业级别挑战 |
| 极限 | ≤ 15 | 几乎不可能 |

隐形检定规则：Master 后台掷 D100，结果 ≤ target = 成功。不显示数字。

### Fail Forward 示例（本类型）

克苏鲁类型的失败代价以**理智损耗**和**不可逆认知污染**为主：

```
侦察检定失败 → 你没发现线索，但你注意到墙角有什么东西在动。
                  看过去——什么都没有。但你确定你看见了。
                  （SAN -2，获得线索「墙角可能有东西」）

聆听检定失败 → 你什么也没听见。但四周突然变得太安静了——
                  连风声都停了。你意识到，在你倾听的这几秒钟里，
                  整栋房子也在「听」你。（SAN -3）
```

每个场景的 `on_fail` 必须同时包含"一个信息"和"一个代价"。绝不返回「你什么也没发现」。

## 序幕场景模板

当玩家选择克苏鲁类型时，以此开场。根据玩家可能有或没有 NPC 同伴，从以下场景中选择最合适的：

**场景 A：海边小镇的来信**

你收到一封来自多年未联系的老友的信。信封上贴着一张异国邮票，邮戳已经模糊不清。信纸边缘泛黄，有几处水渍——

> 我在这里看到了一些东西。不是幻觉。我一开始也以为是幻觉，但那些东西在白天也一样出现。海滩上每天早晨都有足迹，从海水里走上来，又走回海里去。镇上的老渔民告诉我不要在天黑后靠近岸边。——这不是我认识的他们会说的话。我需要你过来。但如果你来，看完这封信就把它烧掉。

你把信折好，放在桌上。窗户外面，天正在暗下来。

你接下来要怎么做？
A. 立刻收拾行李出发
B. 先查阅关于那个沿海小镇的资料
C. 给老友回一封信问问更多细节
D. 烧掉这封信，假装没收到

---

**场景 B：深夜的地下室档案室**

你在镇图书馆的地下档案室做整理工作。这份工作你做了六个月，从未出过任何异常，直到今晚。

你在一个被遗忘的角落里发现了一个被胶带封住的纸箱。纸箱上没有任何标签，但封口处的胶带已经干裂卷曲，像是很多年前贴上去的。你撕开胶带，里面是一沓发黄的简报和一本用线装订的手写笔记。

简报的日期集中在 1910 年到 1915 年之间。内容惊人的一致：失踪。全是失踪。渔民、商贩、过一个路口的旅人——全部在南岸的同一片海岸线上消失。

你翻开那本笔记。封面内侧有一行字：

> 凡看到此页者——请不要继续。

你犹豫了一下。

你接下来要怎么做？
A. 合上笔记，放回纸箱
B. 从头开始阅读这本笔记
C. 把这箱东西带回办公室
D. 先翻翻那些简报的内容
