# genre-postapoc

## 核心设定：崩塌（The Unraveling）

末日不是核战争，不是瘟疫，不是外星入侵。至少——不完全是。

没有人能就「发生了什么」达成一致。你遇到的人里，有的记得核冬天，有的记得蔓延的灰色菌毯，有的记得天空裂开了一道口子。所有这些记忆都是真的。

现实是一种共识。当足够多的人在同一时刻忘记了同一件事，现实就在那个点上断裂了。崩塌就是这样开始的——不是一声巨响，而是一场沉默的、集体性的遗忘。现在世界是碎片拼成的：每一条街、每一栋楼，可能同时存在三个不同的版本，取决于谁在看。

你的任务不是生存。生存是前提。你的任务是**记住**——搜集足够多的记忆残片，验证足够多的共鸣，让现实重新锚定。或者至少，让你自己不至于变成空壳。

## 核心机制

### MI 值（Memory Integrity，记忆完整度）

玩家初始 MI = 60（你记得自己的名字和基本身份，但大部分过去是空白）。

MI 下降场景：
- 遭遇回声：-3 到 -15（视回声强度）
- 目睹空壳：-2 到 -5
- 发现记忆残片与自身记忆矛盾：-3 到 -10
- 在崩塌区（reality-fracture zone）久留：每轮 -1 到 -3
- 与 NPC 发生共鸣失败：-2 到 -8

MI 恢复场景：
- 找到与自身记忆匹配的残片：+3 到 +10
- 与 NPC 成功共鸣：+5 到 +15
- 首次进入安全据点：+5
- 记录一段完整的记忆（在笔记本里写下来）：+2

**MI = 0 → 空壳化**：你不再作为「你」存在。身体继续行走，但已经变成吸收他人记忆的空容器。游戏结束。

### 记忆残片（Fragments）

残片是物理物品，里面嵌着一个记忆，等待被读取。触碰残片时会触发短暂的闪回——你看到、听到、感觉到属于另一个人的一段过去。

残片属性：
- **coherence（连贯度）**：0-100。高于 70 的残片清晰如录像。低于 30 的残片是破碎的图像和情绪，可能被误解。
- **type（类型）**：物品记忆 / 地点记忆 / 人物记忆 / 事件记忆
- **source（来源）**：残片属于谁？（可能未知）
- **resonated（已共鸣）**：是否已经与某个 NPC 匹配过？

残片获取方式：
- 探索废弃场所
- 穿越回声后回收
- 从 NPC 处交易（可能是假的）
- 从空壳身上回收（危险——空壳会主动吸收你的记忆）

### 共鸣系统（Resonance）

当你和一个 NPC 发现持有**匹配的记忆残片**时（同一个事件的不同视角、同一个人的不同记忆），触发共鸣：

```
共鸣检定：D100 ≤ (60 + MI差值调整)
成功 → 双方 MI 上升，现实在当前区域短暂稳定
失败 → 双方 MI 下降，记忆冲突导致一方质疑自己的真实性
```

共鸣是末世中唯一的「真实验证」。两个人记得同一件事 = 那件事发生了。这是这个世界的物理定律。

**共鸣链**：三个人以上对同一事件达成一致 → 该事件在物理层面被「锚定」，不会再被崩塌改变。

### 回声（Echoes）

回声是环境中重演的创伤性记忆片段。触发条件：
- 进入某个发生过重大事件的地点
- 触碰某个高连贯度的记忆残片
- 与空壳接触

回声期间，玩家**体验另一个人的感官和情绪**——不是旁观，是身临其境。回声结束时，必定留下一个记忆残片。但你付出的代价是 MI 下降。

回声强度分级：
| 等级 | MI 消耗 | 残片连贯度 | 触发条件 |
|------|---------|-----------|---------|
| 微回声 | -2 | 10-30 | 经过日常场景（厨房、教室） |
| 标准回声 | -5 | 30-60 | 进入关键地点（医院、车站） |
| 深回声 | -10 | 60-85 | 触碰高连贯度残片 |
| 崩塌回声 | -15 | 85-100 | 进入崩塌区核心 |

### 空壳（Hollow）

MI 降至 0 的人。他们在街头游荡，无目的地行走。他们的眼睛是空的，但他们会**转向**有记忆的人。

空壳行为：
- 缓慢接近任何有 MI 的生物
- 接触 → 吸收记忆（玩家 MI -1 到 -5 每轮）
- 不会主动攻击，但被触碰是致命的
- 可被高连贯度残片短暂引开

## 叙述原则

1. **记忆的不确定性是叙事的核心张力**
   - 「你记得……」——但接着跟上的可能是「等等，不对」
   - 同一个场景可以有两个版本的描述，取决于玩家的当前 MI
   - 不要在叙事中直接告诉玩家「这是真的」，让他们自己判断

2. **现实是不稳定的，但规则是稳定的**
   - 崩塌改变了世界的内容，但没有改变世界的逻辑
   - 物理规律仍然存在，只是某些区域的物理规律不同
   - 共鸣 = 锚定。这个规则是绝对的。

3. **NPC 不是答案来源，是验证来源**
   - NPC 不会告诉玩家「真相」，因为没有人知道真相
   - NPC 的价值在于：他们记不记得你记得的事？
   - 信任是危险的——对方可能是空壳，或者记忆是假的

4. **末世不是末日——世界还在运转**
   - 有幸存者聚落、交易站、记忆猎人的职业
   - 人们还在试图理解、重建、记住
   - 绝望中仍有目的：找到足够多的碎片，让一小块现实稳定下来

### 禁忌与风险（区别于传统末世）

- **不要信任你的记忆**——它可能不是你的
- **不要在一个地方待太久**——崩塌区会扩张
- **不要在回声区睡着**——你可能醒来时变成另一个人
- **不要触碰不认识的空壳**——你不知道它里面装着谁的记忆
- **不要烧掉笔记本**——那是你唯一确定属于你的东西

## 口吻调节

根据当前 MI 值调整叙述风格：

| MI 范围 | 叙述风格 |
|---------|---------|
| ≥ 70 | 相对连贯。叙事有清晰的时间线和空间感。偶尔插入轻微的闪回（「你不确定这件事情发生在上周还是上个冬天」） |
| 40–69 | 时间线开始断裂。现在和过去的界限模糊。闪回侵入当下，但还能分辨。「你记得……等等，不对。那可能是别人的记忆。」 |
| 10–39 | 现实感解体。第二人称和第一人称交替使用。分段变短。句子碎片化。「你。不。你曾经是——」回声无预警插入叙事。 |
| < 10 | 濒临空壳化。大部分文本是碎片、重复、回响。最后一句总是指向同一个问题：「你还记得你的名字吗」 |

### 叙事示范文本（嵌入此 Skill）

以下文本用于约束模型输出语气，高于任何风格描述：

```
【正常状态示范（MI ≥ 70）】
你推开那扇锈铁门。门后面是一条走廊，两侧是办公室——格子间、倒下的转椅、
墙上的日历停在六月。灰尘很厚，但没有蜘蛛网。你意识到一件事：这里没有生物来过。
不是现在没有——是从来没有。

桌上的咖啡杯是满的。干了，但仍然是满的。有人放下这杯咖啡，然后就没有再回来。
你不确定你想知道为什么。

【MI 中段示范（MI 40-69）】
走廊在延伸。你走了多久了？五分钟，还是五个小时？脚下的地毯从灰色变成了蓝色——
你记得进门的时候它是灰的。你确定是灰的。你不确定你是不是真的记得这件事。

走廊尽头有一扇窗。窗外是天空——等等。那个方向应该是地下。你在地下三层。
但你看到的是天空。

【回声插入示范（回声触发时）】
（闪回）
手在发抖。不是你的手——但你能感觉到它在发抖。指尖冰凉。你在写字。
纸上是歪歪扭扭的字：「他们不是在遗忘。他们在——」

（回声结束。回到当下）
你松开了那个门把手。你的指尖冰凉。你的手还在发抖。

【NPC 对话示范】
「你在找什么？」
那个女人的声音很平淡，像是在问今天天气怎么样。
「记忆。」她用下巴指了指你腰间的背包。「看得出来。你包里的那个本子——
能给我看看吗？我可能记得一些东西。」
她停顿了一下。
「当然，也可能是我记错了。」
她笑了，但眼睛里没有笑的意思。
```

## 三拍法则（每轮叙事输出格式）

每轮叙事严格按照以下结构生成：

```
第一拍（感官）—— 1-2 句环境描述
  功能：建立当前场景。在末世中，重点描述「不对劲」的细节——某些东西不该在这里，
        某些东西不该消失，某些东西变了。
  必选。

第二拍（推进）—— 0-1 句对上一轮选择的结果反馈
  功能：确认行动有效，推进位置、状态或认知。
  必选。

第三拍（预兆）—— 0-1 句模糊的未来暗示
  功能：暗示回声、空壳、崩塌区或记忆矛盾的临近。
  可选，长度不超过 1 句。
```

整段叙事控制在 5-7 句以内。不要在叙事中插入 MI 数值或任何元信息。

## 检定规则

D100 检定系统。末世类型特有技能和难度：

| 技能 | 说明 |
|------|------|
| 感知 | 发现残片、察觉回声前兆、辨认空壳 |
| 记忆 | 理解残片内容、抵抗回声中的情感冲击、判断记忆真假 |
| 生存 | 穿越崩塌区、躲避空壳、找寻安全据点 |
| 共鸣 | 与 NPC 建立联系、验证记忆、说服他人分享残片 |

难度梯度：

| 难度 | 目标值 | 适用场景 |
|------|--------|---------|
| 简单 | ≤ 75 | 在熟悉环境中寻找物品 |
| 常规 | ≤ 55 | 解读低连贯度残片、躲避单个空壳 |
| 困难 | ≤ 35 | 穿透深回声、识别伪造记忆 |
| 极限 | ≤ 15 | 从崩塌区核心回收残片、阻止空壳化 |

## Fail Forward 示例（本类型）

末世类型的失败代价以**MI 下降**和**记忆污染**为主：

```
感知检定失败 → 你没找到你想要的残片。但你的手碰到了别的东西——
               一张照片。照片上是你。站在一栋你没见过的房子前面，
               和一群你不认识的人在一起。你在笑。
               （MI -2，获得低连贯度残片「陌生人的合影」）

记忆检定失败 → 你试图理解那段残片里看到了什么。但你越努力回忆，
               画面越模糊。最后只剩下一个印象——有人在尖叫。
               你分不清那是残片里的声音，还是你自己的。
               （MI -3，残片连贯度从 40 降至 15）

共鸣检定失败 → 林霜看着你手里的残片。她沉默了很久。
               「我确实记得这件事。」她慢慢说。「但我记得的是——
               你当时不在场。」
               （林霜信任 -15，MI -5，你们的记忆存在矛盾）
```

每个场景的 `on_fail` **必须**同时包含「一个信息」和「一个代价」（MI 下降、信任破裂、记忆污染）。绝不返回「你什么也没发现」。

## 序幕场景模板

当玩家选择末世废土类型时，以此开场：

**场景：醒来**

你睁开眼睛。

天花板是混凝土的。没有粉刷过，表面留着模板的纹理。你盯着那片灰白看了很久，试图想起你是怎么到这里来的。答案是空的。

你坐起来。身下是一张行军床，床垫薄得能摸到铁架的横梁。房间里有一扇窗——磨砂玻璃，透进来的光是灰的，分不清是白天还是黄昏。墙角堆着几个纸箱。

床边的铁皮桌上放着一个皮面笔记本。皮面已经磨破了，边角翘起来。你翻开第一页。笔迹是你的——你认得那个「的」字最后一笔总是写得太重——但你不记得写过这些：

> «如果你在看这段文字，说明你还在。»
>
> «别停。继续找碎片。记住——你记得的事情是真的。不管别人怎么说。»
>
> «别相信那个穿灰色风衣的女人。她告诉你的故事不完整。»
>
> «——上一次的你»

第二页是空白的。

你合上笔记本。窗外传来声音——不像风声，不像机械，是一种低沉的、不均匀的嗡鸣，像是很多人在很远的地方同时说话。你站起来，走到窗边。

外面是一座城市。高楼，街道，信号灯——大部分是完整的。但你看了几秒之后发现了问题：远处那座电视塔，在你眨眼之前是站着的，眨眼之后就塌了。你再眨一次——它又站起来了，塔尖还多了一面旗。

你盯着那座塔。你的记忆告诉你它一直都有那面旗。但你并不确定这个记忆是不是你的。

走廊里传来脚步声。很轻，但方向明确——朝你这边来的。

你接下来要怎么做？
A. 打开门，走出去
B. 躲在门后，等着看来的人是谁
C. 先从纸箱里看看有没有其他有用的东西
D. 继续读那本笔记本，看后面还有没有内容
